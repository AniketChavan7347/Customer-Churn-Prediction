# 📊 Customer Churn Prediction System

## 📌 Overview

This project is a Machine Learning-based Customer Churn Prediction System that predicts whether a telecom customer is likely to stay or leave (churn) based on customer behavior and service usage patterns.

The application analyzes factors such as contract type, monthly charges, internet service, online security, and tech support to estimate churn probability.

---

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit

---

## 🤖 Machine Learning Model

* Algorithm: Random Forest Classifier
* Accuracy: 79%

### Workflow

* Data Cleaning
* Feature Encoding
* Model Training
* Churn Prediction
* Streamlit Deployment

---

## 💡 Key Insights

* Month-to-month contracts show higher churn risk
* High monthly charges increase churn probability
* Lack of tech support and online security leads to higher customer loss
